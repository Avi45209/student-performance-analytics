# Student Performance Analytics System

## 1. Project Objective
The Student Performance Analytics System is a Python-based project that analyzes student marks and attendance. It calculates total marks, average marks, grades, pass/fail results, subject-wise averages, and identifies top-performing students.

## 2. Technologies Used
- Python
- NumPy
- Pandas
- Google Colab
- GitHub

## 3. Dataset Description
The dataset contains 20 student records with Student ID, Name, Department, Python Marks, Mathematics Marks, AI Marks, and Attendance Percentage.

## 4. Key Features
- Loads student data using Pandas.
- Calculates total and average marks using NumPy.
- Assigns grades using conditional statements.
- Identifies pass and fail students.
- Calculates class performance statistics.
- Analyzes subject-wise averages.
- Identifies the top five performers.
- Analyzes student attendance.
- Exports the final results to a CSV file.

## 5. Grading and Passing Rules
- A: Average marks of 90 or above.
- B: Average marks of 75 to below 90.
- C: Average marks of 60 to below 75.
- D: Average marks of 40 to below 60.
- F: Average marks below 40.
- A student passes only if every subject mark is at least 35.

## 6. How to Run
Open the notebook in Google Colab, upload `students.csv`, and run the code cells in order. The program generates `student_results.csv`.

## 7. Final Outcome
The project successfully analyzes student performance and provides useful information about marks, grades, attendance, and overall academic results.
