# Student Performance Analytics System

## 1. Project Title
Student Performance Analytics System

## 2. Objective
The objective of this project is to analyze student marks and attendance using Python. It calculates total marks, average marks, grades, pass/fail results, subject-wise averages, and identifies top-performing students.

## 3. Technologies Used
- Python
- NumPy
- Pandas
- Google Colab
- GitHub

## 4. Dataset Description
The dataset contains 20 student records. It includes Student ID, Name, Department, Python Marks, Mathematics Marks, AI Marks, and Attendance Percentage.

## 5. Implementation
1. Created a CSV dataset containing student details and marks.
2. Loaded the dataset using Pandas.
3. Used NumPy to calculate total and average marks.
4. Used conditions and functions to assign grades and determine pass/fail status.
5. Used loops and Pandas operations to process student records.
6. Calculated class averages and subject-wise performance.
7. Identified top-performing students.
8. Saved the final results in a CSV file.

## 6. Key Features
- Student data analysis
- Total and average mark calculation
- Grade assignment
- Pass/fail identification
- Subject-wise performance analysis
- Top-performing student identification
- Attendance analysis
- Export of final results

## 7. Output
The program generates student performance results, class statistics, subject averages, and top-performing student information.

## 8. Final Outcome
The project demonstrates how Python, NumPy, and Pandas can be used to analyze student performance and present useful academic information.

## 9. Challenges and Learning
I learned how to load CSV files, work with DataFrames, use NumPy calculations, write functions, apply loops and conditions, and upload project files to GitHub.
